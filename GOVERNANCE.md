# Governance

Vora is currently a maintainer-led experimental open-source project. Muneeb
Shinwari is the repository maintainer and has final responsibility for scope,
releases, security response, and merge decisions.

Contributors influence the project through issues, design proposals, reviews,
tests, documentation, and pull requests. Technical decisions favor clear DSL
semantics, backward compatibility, bounded execution, reproducible evidence,
and honest separation of engine correctness from model quality.

Substantial grammar, provider, persistence, tool-access, or security changes
should be discussed in an issue before implementation. Decisions consider user
value, complexity, compatibility, testability, and maintenance cost. Significant
tradeoffs should be recorded publicly unless security or privacy requires a
private discussion.

As sustained contributors emerge, the project may add reviewers or maintainers
based on demonstrated technical judgment, constructive participation, and
continued responsibility. This document will be updated if governance changes.
